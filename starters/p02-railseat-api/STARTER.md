## Copy it in (task 11)

In Git Bash, in task 11's folder, before you have a `railseat/` folder there:

```bash
cp -r ~/fspy-ess-kit/starters/p02-railseat-api railseat
```

Then do task 11 in `railseat/docs/erd.md`. From task 12 on, copy your `railseat/` folder forward, as every brief says.

## Run it

In `railseat/api/`:

```bash
uv sync                          # makes .venv/ from uv.lock
uv run pytest                    # 1 passed, 1 skipped until task 20, 1 until task 22
uv run fastapi dev app/main.py   # then open http://localhost:8000/docs
```

Until you write them, the endpoints answer 500, and the terminal shows `NotImplementedError: TODO(task NN)`. Alembic, the loader and the tests from task 20 need the cloud lab's PostgreSQL: run `docker compose --profile core up -d` in `~/fspy-ess-kit/cloudlab` first.
